# Clank

> New issues and PRs from new contributors are auto-closed by default.

Clank is a minimal, extensible robot-use harness that you can make your own.

Pose chunks in, joint commands out, for any robot with a URDF. A model, local or hosted, answers with a path for each
arm; clank blends it, solves it into joints while working inside the workcell's safety envelope, and drives the arms.

Ask claude for help
